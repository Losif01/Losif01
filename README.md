## Top Projects

### Smart Palm Sensor and Edge Processing System (Graduation Project)
An IoT architecture designed to detect physical anomalies (insect activity) in agricultural environments through acoustic signal processing. 
* **The Value:** Translates raw environmental noise into actionable data, enabling automated pest control without manual inspection.
* **The Tech:** Engineered the physical hardware layer utilizing the piezoelectric effect and an **ESP32**, coupled with a high-throughput **FastAPI** backend and **PostgreSQL** for telemetry ingestion.

### Self-Hosted Zero-Trust Private Cloud
A fully autonomous, self-hosted infrastructure environment built to completely replace reliance on third-party public cloud providers.
* **The Value:** Guarantees absolute data sovereignty, eliminates recurring hosting costs, and enforces strict security protocols through a customized VPN architecture.
* **The Tech:** Deployed **Nextcloud** via **Ansible** for repeatable IaC configurations, secured network traffic using **Tailscale**, and established real-time observability using **Prometheus** and **Grafana**.

### Lichess Opening Analyzer
A technical data-visualization engine built to analyze extensive chess game datasets for strategic advantages.
* **The Value:** Automates the extraction of complex patterns from large datasets, converting thousands of moves into highly visual, strategic insights for competitive preparation.
* **The Tech:** Leverages **Stockfish** for deep engine evaluations and surfaces analytics through a customized **Streamlit** dashboard.
